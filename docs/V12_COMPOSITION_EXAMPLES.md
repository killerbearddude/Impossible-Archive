# v1.2 Composition Example Sketches

**Status:** v27.3 non-runtime design fixture  
**Scope:** examples for future design review only  
**Runtime effect:** none

These examples describe possible future compositions in prose. They are not JSON schemas, runtime recipes, or resolver instructions. v27.3 continues to use one complete `CivilizationSpec` at a time.

## Example 1 — Delta Bureaucracy with Shrine Copyists

- Base inspiration: `marsh_citadel`
- Candidate fragments: Canal Toll Bureau + Shrine Copyist Interpolation + Calendar Reform Schism
- Intended result: a water-access polity whose public archive is rich but internally unstable because later ritual copyists normalize older canal records.
- Compatibility rationale: `water_access`, `bureaucratic`, `ledger_heavy`, and `ritual_legal` reinforce one another.
- Main conflict to resolve: avoid over-resolving `protected_ambiguity` through excessive administrative evidence.
- Design review question: which evidence remains mundane ledger data and which becomes ritualized legal fiction?

## Example 2 — Mobile Oath Confederacy with Disaster Memory

- Base inspiration: `ash_steppe`
- Candidate fragments: Seasonal Camp Oath + Oral Formula Substitution + Dynastic Reconstruction House
- Intended result: a mobile polity later reconstructed by a sedentary dynasty, creating disagreement between oral oath memory and later written legitimation.
- Compatibility rationale: `nomadic`, `mobile_polity`, `oral_archive`, and `chronology_dispute` provide coherent uncertainty.
- Main conflict to resolve: later copy houses should not erase the mobile evidence ecology.
- Design review question: how are camp names distinguished from lineage names in public evidence?

## Example 3 — Coastal Merchant Salvage League

- Base inspiration: `glass_delta`
- Candidate fragments: Harbor Salvage Court + Glass Furnace Guild + Island Beacon Guild
- Intended result: a harbor/lagoon polity where salvage rights, glass production, and pilotage records create competing public claims.
- Compatibility rationale: `coastal`, `merchant_polity`, `merchant_archive`, `harbor_trade`, and `artifact_rich` are mutually reinforcing.
- Main conflict to resolve: artifact abundance can reduce mystery unless discovery years and provenance damage are staged.
- Design review question: which institution controls foreign-name translation, and who benefits from mistranslation?

## Example 4 — Highland Salt Oracle Court

- Base inspiration: `hill_oracle` or `salt_terrace_kingdom`
- Candidate fragments: Oracle Boundary College + Salt Spring Purity Court + Fire-Damaged Granary Archive
- Intended result: a highland landscape where pasture, salt, spring access, and ritual purity create overlapping legal records.
- Compatibility rationale: `highland`, `arid_basin`, `ritual_legal`, `bureaucratic`, and `ledger_heavy` can coexist with careful site scoping.
- Main conflict to resolve: avoid turning every dispute into a generic court case.
- Design review question: which titles are offices, which are ritual masks, and which are later misread as persons?

## Example 5 — Frozen Mire Seasonal Law

- Base inspiration: `frost_mire_accord`
- Candidate fragments: Peat Preservation and Thaw-Court + Seasonal Camp Oath + Oral Formula Substitution
- Intended result: a cold wetland polity whose winter and summer legal geographies contradict each other in public evidence.
- Compatibility rationale: `wetland`, `tundra`, `fragile_archive`, `oral_archive`, and `truth_partial` support seasonal ambiguity.
- Main conflict to resolve: portable oath evidence must still connect to stable hidden entities/events.
- Design review question: what public artifact proves a route existed only seasonally without exposing hidden truth?

## Boundary statement
